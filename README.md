Полнофункциональный MVP цифрового кредитного конвейера для малого и микробизнеса, разработанный для хакатона **Альфа-Банка**.

Решение объединяет путь заемщика (выбор продукта, подача заявки, автообогащение, прозрачный скоринг, акцепт офера) и внутреннее рабочее место кредитного риск-андеррайтера в единый управляемый процесс.

---

## 🌟 Ключевые возможности

### 🏢 Для предпринимателя (МСП и ИП)
- **Витрина кредитных продуктов:** Оборотный капитал, Развитие бизнеса, Финансирование оборудования.
- **Интерактивный кредитный калькулятор:** моментальный расчет аннуитета, графика платежей и переплаты.
- **Мастер оформления заявки за 4 шага:**
  - Автоматическое заполнение реквизитов организации по ИНН (синтетический справочник ЕГРЮЛ/ФНС);
  - Валидация лимитов суммы и срока продукта на клиенте и сервере;
  - Прикрепление документов (бухгалтерская отчетность, выписка).
- **Сквозной трекинг конвейера:** визуализация движения заявки в реальном времени (`Черновик` → `Валидация` → `ФНС/БКИ` → `Скоринг` → `Решение`).
- **Прозрачный скоринг:** отображение факторов оценки (положительные и отрицательные влияния), понятные объяснения без сложного банковского жаргона.
- **Электронное подписание:** принятие или отклонение кредитного предложения в 1 клик.

### 🏦 Для сотрудника банка (АРМ Андеррайтера)
- **Очередь заявок:** фильтрация по статусам, группировка, поиск по номеру, ИНН и наименованию.
- **Комплексное досье заемщика:**
  - Финансовые коэффициенты (выручка, чистая прибыль, коэффициент долговой нагрузки DSTI);
  - Результаты проверок ФНС (налоговая задолженность, приостановления счетов по ст. 76 НК РФ);
  - Данные БКИ (кредитный рейтинг, активные кредиты, просрочки 0 / 1–30 / 90+ дней);
  - Проверка легитимности по ЕГРЮЛ и проверка судебных исков (Арбитраж / ФССП).
- **Принятие экспертных решений:**
  - Одобрение на стандартных условиях;
  - Встречное предложение (коррекция суммы, срока или ставки для снижения кредитного риска);
  - Запрос дополнительных сведений или документов у клиента;
  - Отказ с фиксацией сработавших стоп-факторов и комментариев.
- **Полный аудит:** фиксация автора, времени и оснований каждого действия.

## 🚀 Быстрый запуск (Makefile / Docker)

Проект полностью контейнеризирован и запускается одной командой без необходимости ручной установки зависимостей.

### Рекомендуемый способ (через Makefile):

```bash
# Собрать контейнеры и запустить весь проект в фоне
make run
```

### Основные команды Makefile:

| Команда | Описание |
| :--- | :--- |
| `make run` (или `make up`) | Собрать образы и запустить проект (Frontend + Backend + PostgreSQL) |
| `make down` (или `make stop`) | Остановить и удалить все контейнеры проекта |
| `make restart` | Перезапустить все сервисы |
| `make logs` | Просмотр объединенных логов в реальном времени (`logs-backend`, `logs-frontend`) |
| `make test` | Запустить автотесты бэкенда (`pytest`) внутри Docker-контейнера |
| `make seed` | Заново накатить эталонные демо-данные (сценарии A, B, C, D) |
| `make shell` | Открыть интерактивную консоль Django (`manage.py shell`) |
| `make clean` | Полная очистка: остановка контейнеров с удалением томов данных |
| `make help` | Вывести список всех доступных целей Makefile |

<details>
<summary><b>Запуск через прямой вызов Docker Compose (без Make)</b></summary>

```bash
docker compose up --build -d
```
</details>

После завершения сборки и запуска доступны следующие сервисы:

| Сервис | URL | Назначение |
| :--- | :--- | :--- |
| **Frontend (React)** | [http://localhost:3000](http://localhost:3000) | Пользовательский интерфейс предпринимателя и банка |
| **Backend REST API** | [http://localhost:8000/api/v1/](http://localhost:8000/api/v1/) | Серверные эндпоинты конвейера |
| **Swagger UI / OpenAPI** | [http://localhost:8000/api/v1/docs/](http://localhost:8000/api/v1/docs/) | Интерактивная документация API |
| **ReDoc** | [http://localhost:8000/api/v1/redoc/](http://localhost:8000/api/v1/redoc/) | Альтернативная спецификация API |
| **Django Admin** | [http://localhost:8000/admin/](http://localhost:8000/admin/) | Панель администратора Django |

> **Автоматический сидер данных:** При старте контейнера `backend` автоматически применяются миграции базы данных и выполняется команда `python manage.py seed_demo_data`, создающая тестовые компании, учетные записи и заявки для всех 4 сценариев!

## 🧪 Пошаговый сценарий тестирования жюри

### Шаг 1. Проверка Сценария A (Автоматическое одобрение)
1. Откройте [http://localhost:3000](http://localhost:3000).
2. На верхней панели нажмите **«Сценарий A: Автоодобрение»**.
3. Вы перейдете в кабинет ООО «ТехноПрогресс». Нажмите на заявку `#ALFA-DEMO-001A`.
4. Обратите внимание на статус `Предложение готово`, скоринговый балл `100/100` и одобренную сумму `3 000 000 ₽`.
5. Нажмите зеленую кнопку **«Принять предложение и получить финансирование»**. Заявка мгновенно перейдет в статус `COMPLETED` (кредитный договор оформлен).

### Шаг 2. Проверка Сценария B (Встречное предложение)
1. На верхней панели нажмите **«Сценарий B: Встречное»**.
2. Откройте заявку `#ALFA-DEMO-002B` (ИП Иванов А.С.).
3. Изучите обоснование: заемщик запросил 6 000 000 ₽, но алгоритм ограничил сумму до `3 600 000 ₽` (30% годовой выручки), чтобы не допустить кассового разрыва.

### Шаг 3. Проверка Сценария C (Ручное рассмотрение андеррайтером)
1. На верхней панели нажмите **«Сценарий C: Андеррайтинг»**.
2. Откройте заявку `#ALFA-DEMO-003C` (ООО «Вектор Плюс»). Обратите внимание на статус `На рассмотрении андеррайтера`.
3. На верхней панели переключитесь на **«Кабинет банка»** (вход под сотрудником `officer_alfa`).
4. В очереди заявок откройте `#ALFA-DEMO-003C` кнопкой **«Рассмотреть»**.
5. Ознакомьтесь с досье: финансовые метрики, результаты проверок ФНС и БКИ, факторы риска.
6. Нажмите **«Принять решение андеррайтера»**, выберите вкладку `Одобрить` или `Запросить данные` и подтвердите решение.
7. Вернитесь в сценарий C: клиент видит обновленное решение в реальном времени!

### Шаг 4. Проверка Сценария D (Отказ по стоп-факторам)
1. Нажмите **«Сценарий D: Отказ»**.
2. Откройте заявку `#ALFA-DEMO-004D` (ООО «СтройНеликвид»).
3. Обратите внимание на статус `Отказано`, скоринг `0/100`, список стоп-факторов и понятные рекомендации клиенту.

## 🛠 Технологический стек

- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, shadcn/ui components, Lucide React, React Router, Axios.
- **Backend:** Python 3.12, Django 5.1, Django REST Framework, drf-spectacular (OpenAPI 3.0), pytest + pytest-django.
- **База данных:** PostgreSQL 16 (с поддержкой SQLite для локальных тестов).
- **Инфраструктура:** Docker, Docker Compose, Nginx, Gunicorn, GitHub Actions CI/CD.
