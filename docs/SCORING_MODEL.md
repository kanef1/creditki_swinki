# Скоринговая модель и логика кредитных решений

В соответствии с требованиями ТЗ (страница 14 кейса Альфа-Банка) **скоринг и кредитное решение строго разделены на две независимые логические сущности**:
1. **Скоринговый движок (`scoring`):** оценивает объективный уровень кредитного риска заемщика (0-100 баллов).
2. **Модуль кредитных решений (`decisions`):** учитывает оценку риска, лимиты конкретного продукта, стоп-факторы и формирует итоговые условия (одобрение, встречное предложение, ручной андеррайтинг или отказ).

---

## 1. Детерминированный Rule-Based Scoring Engine

Базовый уровень оценки: **50 баллов**. Итоговый балл ограничен диапазоном **[0, 100]**.

### 1.1. Факторы оценки и весовые коэффициенты

| Фактор | Условие проверки | Влияние на балл | Обоснование риска |
| :--- | :--- | :---: | :--- |
| **Возраст бизнеса** | < 6 месяцев | **-20** (Стоп-фактор) | Высокая смертность стартапов на ранней фазе |
| | 6–12 месяцев | **-5** | Формирующаяся клиентская база |
| | 1–3 года | **+10** | Устойчивое функционирование на рынке |
| | > 3 лет | **+15** | Зрелый стабильный бизнес |
| **Финансовый результат** | Чистый убыток | **-25** | Убыточная деятельность ставит под угрозу возврат |
| | Прибыль > 0, маржа < 10% | **+5** | Базовая операционная рентабельность |
| | Прибыль > 0, маржа >= 10%| **+15** | Высокая рентабельность бизнеса |
| **Отношение долга к выручке** | Кредит <= 10% годового оборота | **+15** | Минимальная нагрузка на денежный поток |
| | Кредит <= 25% годового оборота | **+10** | Комфортный уровень заимствования |
| | Кредит <= 40% годового оборота | **0** | Нейтральный диапазон |
| | Кредит > 40% годового оборота | **-20** | Риск дефолта из-за избыточного долга |
| **Коэффициент DSTI** | DSTI <= 20% | **+15** | Платежи по всем долгам легко покрываются доходами |
| *(Debt Service to Income)* | 20% < DSTI <= 35% | **+5** | Приемлемая кредитная нагрузка |
| | 35% < DSTI <= 50% | **-10** | Повышенное давление на оборотный капитал |
| | DSTI > 50% | **-25** | Критическая нагрузка (платежи > 50% доходов) |
| **Налоговая дисциплина** | Нет задолженностей и арестов ФНС | **+10** | Добросовестный налогоплательщик |
| | Задолженность ФНС / Блокировка счетов | **-35** (Стоп-фактор) | Риск безакцептного списания средств ФНС |
| **Кредитная история (БКИ)**| Рейтинг >= 750, 0 просрочек | **+15** | Безупречная платежная дисциплина |
| | Имелись исторические задержки <= 30 дн.| **-10** | Сигнал умеренной платежной волатильности |
| | Открытая просрочка > 90 дней | **-40** (Стоп-фактор) | Дефолтное состояние заемщика |

## 2. Стоп-факторы (Безусловный отказ)

При срабатывании любого из следующих стоп-факторов заявка не подлежит кредитованию:
1. `TAX_DEBT_PRESENT`: Наличие открытой задолженности перед бюджетом по данным ФНС или блокировка расчетных счетов по ст. 76 НК РФ.
2. `BKI_CRITICAL_OVERDUE`: Наличие текущей или недавней просроченной задолженности свыше 90 дней по данным Бюро кредитных историй.
3. `COMPANY_LIQUIDATION`: Статус ликвидации, реорганизации или банкротства в ЕГРЮЛ.
4. `MASS_DIRECTOR_OR_ADDRESS`: Признаки номинальности руководителя или массового адреса регистрации.
5. `SEVERE_LOSS`: Чистый убыток предприятия, превышающий 1 000 000 руб.

## 3. Градации риска и логика принятия решений

| Скоринговый балл | Уровень риска | Рекомендация | Кредитное решение |
| :---: | :---: | :---: | :--- |
| **75 – 100** | `LOW` | `AUTO_APPROVE` | **Автоматическое одобрение** на запрашиваемых условиях. Бонус к ставке (-0.5%) при балле >= 85. |
| **75 – 100** | `MEDIUM` | `COUNTER_OFFER` | **Встречное предложение**: сумма снижается до безопасного лимита (30% годовой выручки), если заемщик запросил избыточный объем. |
| **50 – 74** | `MEDIUM` | `MANUAL_REVIEW` | **Ручное рассмотрение андеррайтером**: заявка передается в АРМ кредитного сотрудника с описанием факторов риска. |
| **< 50** или Стоп-фактор | `CRITICAL` | `REJECT` | **Отказ** с прозрачным текстовым объяснением причин и советами по исправлению ситуации. |
