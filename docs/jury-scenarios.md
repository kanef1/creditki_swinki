# Сценарии для жюри

Все данные синтетические, правила не являются кредитной политикой Альфа-Банка. В каждой демо-сессии создаются собственные компании и 4 исходные заявки. В базе сохраняются финансовые снимки, результаты ФНС/БКИ, скоринг, решение и история. ИНН экземпляров отличаются между сессиями; использовать нужно ИНН, показанный в интерфейсе.

Ставка берётся из текущего синтетического продукта (исходно 19,50%), а не из примера на скриншоте. Продукт по умолчанию — первый в каталоге «Оборотные средства». Сценарии автоматически проверяют его ограничения по сумме/сроку. Если каталог изменить несовместимым образом, запуск вернёт объяснимую ошибку.

1. Открыть модуль без входа. Раскрыть «Сценарии для жюри» в «Продукте», изучить показатели.
2. «Подставить данные» выбирает компанию на главном экране; выбрать кредит, проверить условия и финансовые показатели, затем отправить заявку.
3. «Запустить» создаёт новую заявку в PostgreSQL и выполняет реальные сервисы проверки/скоринга/решения. Результат открывается в четвёртом разделе. Это не переключение frontend-статуса.
4. В «Результате» исходные показатели новой сессии: 4 заявки, 1 ручное рассмотрение, 2 с оффером, 1 отказ банка; сумма действующих офферов 9,5 млн ₽. Числа меняются при действиях.
5. Принять один оффер, отклонить другой. Отклонённый оффер останется в истории, но его сумма уйдёт из статистики действующих/принятых предложений. Деньги не выдаются.
6. Проверить таблицы «Все заявки» и «История офферов», фильтр статуса, поиск по названию/ИНН, «Детали». В карточке сохранены все версии оффера данной заявки, причины и переходы состояния.
7. Сценарий MANUAL_REVIEW остаётся на рассмотрении; сотрудник может принять решение через защищённый банковский API/Postman. Кнопка жюри не даёт посетителю роль сотрудника и не обходит это ограничение.
8. Открыть приватное окно: оно получает независимую демо-среду, а не доступ к заявкам первого посетителя.

Повтор context/ не дублирует исходные заявки. Сценарии и гостевой набор отключаются при DEMO_VISITOR_ENABLED=0; в рабочем банковском окружении требуется проверенная идентичность основного приложения.


Выбор компании находится на главном экране перед кредитными продуктами. Выручка и прибыль показаны за фактический период работы, максимум за 12 месяцев; данные не экстраполируются на год. У молодого бизнеса за 3 месяца выручка 650 тыс. ₽, убыток 120 тыс. ₽, долг 800 тыс. ₽, долг ФНС 110 тыс. ₽ и просрочка 15 дней. Старые отправленные заявки сохраняют прежние финансовые данные.
