# Модель rules-v1

Учебные проектные допущения; не правила Альфа-Банка. Финансовые поля — рубли за 12 месяцев, Decimal на backend. Калькулятор — стандартный аннуитет без комиссий и страховки; он не определяет решение.

| Фактор | Баллы |
|---|---|
| Возраст ≥24 / ≥12 / <12 месяцев | 20 / 10 / 0 |
| Прибыль/выручка ≥15% / >0 / ≤0 | 20 / 10 / 0 |
| Долг/выручка ≤30% / ≤60% / >60% | 20 / 10 / 0 |
| Синтетический балл БКИ ≥750 / ≥600 / <600 | 25 / 10 / 0 |
| Запрашиваемая сумма ≤30% выручки / выше | 15 / 5 |

Максимум 100. Риск LOW при ≥80, MEDIUM при 50–79, HIGH ниже 50 или при стоп-факторе. Стоп-факторы: компания не действует, просрочка >60 дней, налоговая задолженность >100000, нулевая выручка. Форма отправки требует положительную выручку; нулевой показатель дополнительно защищён движком.

Отдельный decision engine: стоп-фактор или <50 → REJECTED; 50–79 → MANUAL_REVIEW; ≥80 → OFFER_READY. Для низкого риска лимит ограничен 30% выручки: если запрошено больше, создаётся встречное предложение. Если лимит ниже минимальной суммы продукта, назначается ручное рассмотрение. Сотрудник может одобрить сумму в пределах продукта и не выше запрошенной, отказать или запросить сведения с обоснованием ≥10 символов.

Mock FNS и BKI детерминированно читают синтетический профиль компании. FNS сохраняет active, tax_debt, age_months; BKI — credit_score и overdue_days. Каждый результат содержит synthetic=true и revision. Внешних запросов, случайного выбора сценария, ML и LLM нет. Изменение входных данных меняет результат вычисления. Профили A/B/C/D — входные данные, результаты не зашиты во frontend.
