# Визуальный ориентир

Пользователь указал https://alfabank.ru/ как основной референс. 22 октября 2026 прямое открытие главной страницы инструментом web вернуло тайм-аут, /sme/ и страницы бизнес-кредита — 502; прямой HTTP-запрос из окружения тоже не прошёл. Актуальный вид главной страницы не проверен. Поисковые фрагменты не подтверждают её дизайн; старые изображения из сторонних публикаций не использованы как актуальный референс.

Поэтому интерфейс опирается на визуальные требования мастер-промпта: красный акцент, чёрная типографика, белые и нейтральные серые поверхности, крупные заголовки и простые действия. Сайт, логотип, фотографии и фирменные иллюстрации не копируются. Бренд «Дело» — независимый прототип, не официальный банковский продукт. Условия синтетические.

Скорректированы основные фоновые поверхности: убран бежевый тон hero/login, красная основная кнопка сохранена как главный акцент. Адаптивные CSS и focus-состояния есть; визуальная проверка результата в браузере остаётся открытой, поскольку доступных браузеров в среде нет. Этот документ не подтверждает пиксельное соответствие сайту банка.
